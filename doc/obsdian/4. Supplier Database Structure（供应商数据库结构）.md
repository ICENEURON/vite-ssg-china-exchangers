# Supplier Database Structure for Supabase (V2)

## Overview
This document defines the relational database schema for HeatEx Direct to be deployed on **Supabase (PostgreSQL)**. 
Based on requirements, the architecture consolidates general textual capabilities directly into the core tables using `JSONB`, cleanly extracts **Media/Storage Assets** into unified relation tables using an `asset_type` discriminator, and utilizes dictionary lookup tables for standardizing global filter values.

---

## 1. Dictionaries & Lookups

### `countries`
Standardized ISO country data dictionary.

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `text` | Primary Key (e.g., 'CN', 'US'). |
| `name` | `text` | Country name. |
| `cca2` / `cca3` | `text` | Country codes. |
| `independent` | `boolean` | Sovereignty status. |
| `region` / `subregion` | `text` | Geographical categorization. |

### `industries`
Standardized list of application industries.

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `bigint` | Primary Key. |
| `slug` | `text` | URL-friendly identifier. |
| `name` | `jsonb` | Multi-language localized name. |
| `is_visible` | `boolean` | Visibility toggles for the frontend. |

## 3. Unified Assets Architecture

Files uploaded to **Supabase Storage** will register their unique paths (`storage_path`) into the following unified relation tables.

### `manufacturer_assets`
A unified table for all factory-level media/documents. Differentiated via `asset_type`.

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `uuid` | Primary Key. |
| `manufacturer_id` | `uuid` | Link to `manufacturers.id`. |
| `asset_type` | `text` | e.g., `media`, `certificate`, `logo`, `document`. |
| `alt_text` | `text` | Image alt tag or Document title. |
| `storage_bucket` | `text` | Target bucket (e.g., `platform-media`). |
| `storage_path` | `text` | Storage Bucket file ID/Path. |
| `file_name` | `text` | Original uploaded file name. |
| `file_type` | `text` | File extension (e.g., `pdf`, `jpg`). |
| `created_at` | `timestamp` | Storage lifecycles. |
| `updated_at` | `timestamp` | Storage lifecycles. |

### `product_assets`
A unified table for all product-level media/documents. Differentiated via `asset_type`.

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `uuid` | Primary Key. |
| `product_id` | `uuid` | Link to `products.id`. |
| `asset_type` | `text` | e.g., `gallery_image`, `technical_drawing`, `certificate`. |
| `alt_text` | `text` | Image alt tag or Document title. |
| `storage_bucket` | `text` | Target bucket (e.g., `platform-media`). |
| `storage_path` | `text` | Storage Bucket file ID/Path. |
| `file_name` | `text` | Original uploaded file name. |
| `file_type` | `text` | File extension (e.g., `pdf`, `jpg`). |
| `created_at` | `timestamp` | Storage lifecycles. |
| `updated_at` | `timestamp` | Storage lifecycles. |

## 3. 统一附件管理架构 (Unified Assets Architecture)

所有包含真实实体的图纸、图片、PDF 等文件，统一部署入以下高内聚资产结构。

### `manufacturer_assets` (工厂相关资产统合)
通过 `asset_type` 字段，一张表兼容之前分离的车间照片 (`media`)、证书 (`certificate`)、合作品牌 Logo (`logo`) 以及 下载型手册 (`document`)。

| 列名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `id` | `uuid` | 主键。 |
| `manufacturer_id` | `uuid` | 关联 `manufacturers.id`。 |
| `asset_type` | `text` | 分类界定（如: `media`, `certificate`, `logo`, `document`）。 |
| `alt_text` | `text` | 图片的 Alt 标签或者文档表述名称。 |
| `storage_bucket` | `text` | Storage 所在存储桶。 |
| `storage_path` | `text` | Storage 存储桶里的文件ID/详细路径。 |
| `file_name` | `text` | 原始用户上传包含后缀的文件名。 |
| `file_type` | `text` | 文件扩展名后缀（如 `pdf`, `png`）。 |
| `created_at` | `timestamp`| 时间戳。 |
| `updated_at` | `timestamp`| 时间戳。 |

### `product_assets` (产品相关资产统合)
同理，用于管理归属于某一确定型号产品的多张产品图册或是专属的技术说明图。

| 列名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `id` | `uuid` | 主键。 |
| `product_id` | `uuid` | 关联 `products.id`。 |
| `asset_type` | `text` | 分类界定（如 `gallery_image` 主图, `technical_drawing` 图纸）。 |
| `alt_text` | `text` | 描述名称用于 SEO 或是提示。 |
| `storage_bucket` | `text` | 所在的存储桶。 |
| `storage_path` | `text` | Storage 存储桶里的详细路径。 |
| `file_name` | `text` | 文件原始名。 |
| `file_type` | `text` | 扩展名后缀。 |
| `created_at` | `timestamp`| 时间戳。 |
| `updated_at` | `timestamp`| 时间戳。 |
