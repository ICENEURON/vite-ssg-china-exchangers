# Buyer Guide / 买家指南

Last updated: 2026-05-08.

## English

HeatEx Direct helps industrial buyers discover and evaluate Chinese heat exchanger manufacturers. It is intended for procurement managers, engineers, EPC teams, distributors, and industrial system integrators.

### What Buyers Can Do

- Browse manufacturer profiles.
- Compare products and applications.
- Review company descriptions, industries, export markets, certificates, images, and documents where available.
- Read industry news and technical content when the blog is enabled.
- Submit a structured RFQ after email verification.

### How to Use the Directory

Start with the manufacturer list if the supplier is the main decision. Start with the product list if equipment type or application is the main decision. Product detail pages link back to their manufacturers, and manufacturer profiles include related product summaries.

### RFQ Process

The current RFQ flow has four steps:

1. Enter project context: name, company, country, and industry.
2. Enter thermal and design parameters: fluids, phase types, mass flow, temperature, material, pressure, flange standard, and notes.
3. Verify email through Supabase OTP.
4. Review and submit.

After submission, the request is stored in HeatEx Direct's Supabase `rfqs` table. Current code does not automatically send the request to manufacturers. Follow-up and routing should be treated as a platform operation unless a later implementation changes this behavior.

### Anonymous Mode

RFQ includes an anonymous/stealth flag. It stores whether the buyer wants initial identity protection. Since automatic supplier dispatch is not currently implemented, this flag should be understood as a data preference for future or manual handling.

### Best Practices

- Provide real operating parameters instead of vague descriptions.
- Include media names, fluid phases, mass flow, temperatures, material requirements, pressure, and flange standards when possible.
- Use a business email when available to improve request credibility.
- Compare suppliers by technical fit, certifications, product specialization, and documentation quality.

## 中文

HeatEx Direct 帮助工业采购方发现和评估中国换热器制造商。典型用户包括采购经理、工程师、EPC 团队、经销商和工业系统集成商。

### 采购方可以做什么

- 浏览制造商资料页。
- 比较产品和应用行业。
- 查看公司介绍、行业、出口市场、证书、图片和文档等信息。
- 在博客开启时阅读行业资讯和技术内容。
- 通过邮箱验证后提交结构化 RFQ。

### 如何使用目录

如果采购决策首先取决于供应商能力，可以从厂家列表开始。如果决策首先取决于设备类型或应用场景，可以从产品列表开始。产品详情页会关联对应厂家，厂家资料页也会展示相关产品摘要。

### RFQ 流程

当前 RFQ 有四步：

1. 填写项目背景：姓名、公司、国家和行业。
2. 填写热工和设计参数：流体、相态、质量流量、温度、材料、压力、法兰标准和备注。
3. 通过 Supabase OTP 验证邮箱。
4. 确认并提交。

提交后，请求会写入 HeatEx Direct 的 Supabase `rfqs` 表。当前代码不会自动把询价发送给制造商。后续跟进和分发应视为平台运营流程，除非未来代码实现改变这一行为。

### 匿名模式

RFQ 包含匿名/隐身标记，用于记录采购方是否希望在初期保护身份。由于当前尚未实现自动供应商分发，该标记目前应理解为供未来或人工处理使用的数据偏好。

### 使用建议

- 尽量提供真实工况参数，而不是宽泛描述。
- 尽可能填写介质名称、相态、质量流量、温度、材料、压力和法兰标准。
- 使用企业邮箱可以提升询价可信度。
- 评估供应商时关注技术匹配度、认证、产品专长和资料完整度。
